# React Custom Hook - useFetch

This project demonstrates a reusable custom React hook `useFetch`
for fetching API data with loading and error handling.

## Features
- Custom `useFetch` hook
- API integration
- Grid layout UI
- Image modal on click

## API Used
https://api.escuelajs.co/api/v1/products

## Tech Stack
- React
- Vite
- JavaScript
- CSS
